# saasPlug Web

Reusable Next.js frontend imported from
`/Users/zak/university/soft-eng/softeng25-02/front-end`.

This app currently seeds the saasPlug EVUser experience:

- charger map and list
- charger details
- reservation and charging flows
- EV user signin/signup screens
- vehicle management
- EV user billing history
- profile and problem-reporting screens

ProviderAdmin and PlatformOperator screens are intentionally not added yet
because this pass only imports and adapts reusable code from the previous
project.

## Run

```bash
cp .env.example .env.local
npm install
npm run dev
```
